# ⚡ ForgeOS

**AI-native product execution system for ideas, projects, tasks, docs, and code.**

ForgeOS is a founder-grade operating system for managing the full product lifecycle — from capturing ideas to shipping code. Built for solo builders, indie hackers, and AI-native developers who use GitHub and Claude Code.

---

## Features

- **Ideas** — Capture, AI-enrich, score, and convert to projects
- **Projects** — Stage-based workflow (Clarifying → Shipped), health scores, activity feeds
- **Tasks** — Kanban board + list view, drag-and-drop, dependencies, bulk operations
- **Docs** — Markdown editor with preview, AI-generated MVP specs
- **Dashboard** — Next-best-action, velocity trends, blocked task alerts
- **Analytics** — Task completion charts, project progress, AI usage stats
- **GitHub** — Webhook sync, PR tracking, check run status, task-to-PR linking
- **AI Workflows** — Idea enrichment, task generation, spec generation, Claude Code prompts
- **Search** — Cmd+K command palette across all entities
- **Weekly Review** — Activity summary and stale project detection
- **Notifications** — In-app bell with unread count
- **Templates** — Customizable AI prompt templates with variable substitution
- **Auth** — Email/password + GitHub OAuth via NextAuth
- **Theme** — Dark/light mode toggle

## Quick Start

### Option 1: Setup Script (Recommended)

```bash
git clone https://github.com/Wrexist/JarvisOS.git
cd JarvisOS
./setup.sh
pnpm dev
```

The setup script checks dependencies, creates `.env`, sets up the database, runs migrations, and seeds demo data.

### Option 2: Docker

```bash
git clone https://github.com/Wrexist/JarvisOS.git
cd JarvisOS
docker-compose up
```

### Option 3: Manual

```bash
git clone https://github.com/Wrexist/JarvisOS.git
cd JarvisOS
cp .env.example .env            # Edit DATABASE_URL and AUTH_SECRET
pnpm install
pnpm db:migrate
pnpm db:seed
pnpm dev
```

Then open **http://localhost:3000**

## Project Structure

```
src/
  app/           # Next.js pages and API routes
  components/    # React components (layout, features, ui)
  server/        # Service layer (business logic)
  lib/           # Utilities (prisma, auth, ai, validation)
prisma/          # Schema, migrations, seed
```

## Environment Variables

| Variable | Required | Description |
|----------|----------|-------------|
| `DATABASE_URL` | Yes | PostgreSQL connection string |
| `AUTH_SECRET` | Yes | NextAuth secret (auto-generated by setup.sh) |
| `ANTHROPIC_API_KEY` | No | Enables AI features (enrichment, generation) |
| `GITHUB_CLIENT_ID` | No | Enables GitHub OAuth login |
| `GITHUB_CLIENT_SECRET` | No | Enables GitHub OAuth login |
| `GITHUB_WEBHOOK_SECRET` | No | Verifies GitHub webhook signatures |

## Architecture

- **Server Components** by default for data fetching
- **Service Layer** (`src/server/services/`) for all business logic
- **Thin API Routes** that delegate to services
- **Zod Validation** on API inputs
- **Activity Events** logged on all major actions
- **Health Scores** computed from task completion and staleness
